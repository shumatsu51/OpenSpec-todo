## Why

利用者が Todo 一覧の進捗をひと目で把握できるようにするため、一覧の総数、完了済み数、未完了数を常に表示する必要があります。既存の追加・完了切替・削除操作に連動して表示します。

## What Changes

- 画面タイトル「Todo」の右側に、すべて・完了済み・未完了のタスク数を表示する。
- すべては黒、完了済みは緑、未完了は赤で表示する。
- Todo の追加、完了状態の切替、削除、および保存済み一覧の復元後に、各件数を現在の一覧に合わせて表示する。

## Capabilities

### New Capabilities

- なし。

### Modified Capabilities

- `todo-management`: Todo 一覧の現在の総数、完了済み数、未完了数を画面タイトルの右側に表示する要件を追加する。

## Impact

- Todo 画面の表示コンポーネントとスタイルを更新する。
- 既存の Todo 状態から派生した件数を表示するため、データ保存形式や外部依存は変更しない。
