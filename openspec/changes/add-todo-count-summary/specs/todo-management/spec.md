## ADDED Requirements

### Requirement: Todo 件数の表示
システムは、画面タイトル「Todo」の右側に、現在の Todo 一覧の「すべて」「完了済み」「未完了」の件数を表示しなければならない（MUST）。すべての件数は黒、完了済みの件数は緑、未完了の件数は赤で表示しなければならない（MUST）。

#### Scenario: Todo がない状態の件数を表示する
- **WHEN** Todo 一覧が空である
- **THEN** すべて、完了済み、未完了の件数はいずれも 0 として指定された色で表示される

#### Scenario: Todo を追加した後に件数を更新する
- **WHEN** 利用者が未完了の Todo を1件追加する
- **THEN** すべてと未完了の件数が1増え、完了済みの件数は変わらない

#### Scenario: 完了状態を切り替えた後に件数を更新する
- **WHEN** 利用者が未完了の Todo を完了に切り替える
- **THEN** 完了済みの件数が1増え、未完了の件数が1減り、すべての件数は変わらない

#### Scenario: Todo を削除した後に件数を更新する
- **WHEN** 利用者が Todo を1件削除する
- **THEN** 削除した Todo の状態に応じて、すべてと該当する完了済みまたは未完了の件数が1減る

#### Scenario: 保存済みの Todo を復元した後に件数を表示する
- **WHEN** 利用者が保存済みの Todo 一覧を持つ状態でアプリを再読み込みする
- **THEN** 復元された一覧に基づくすべて、完了済み、未完了の件数が表示される
