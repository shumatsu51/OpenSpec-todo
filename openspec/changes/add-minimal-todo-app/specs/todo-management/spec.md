## Purpose

利用者が小さな Todo 一覧を管理し、同じブラウザで後から開き直しても一覧と完了状態を継続して利用できるようにする。

## ADDED Requirements

### Requirement: Todo の追加
システムは、利用者が空白のみではないタイトルを入力して追加操作を行ったとき、新しい未完了の Todo を一覧に追加しなければならない（MUST）。追加後、入力欄は空にしなければならない（MUST）。

#### Scenario: タイトルを入力して Todo を追加する
- **WHEN** 利用者が「牛乳を買う」と入力して追加する
- **THEN** 一覧には「牛乳を買う」という未完了の Todo が表示され、入力欄は空になる

#### Scenario: 空白のみの Todo は追加しない
- **WHEN** 利用者が空白のみを入力して追加する
- **THEN** 一覧に新しい Todo は追加されない

### Requirement: Todo の完了状態の切り替え
システムは、利用者が一覧内の Todo を操作したとき、その Todo の完了状態を未完了と完了の間で切り替えなければならない（MUST）。

#### Scenario: 未完了の Todo を完了にする
- **WHEN** 利用者が未完了の Todo の完了状態を操作する
- **THEN** その Todo は完了として表示される

#### Scenario: 完了した Todo を未完了に戻す
- **WHEN** 利用者が完了した Todo の完了状態を操作する
- **THEN** その Todo は未完了として表示される

### Requirement: Todo の削除
システムは、利用者が Todo の削除操作を行ったとき、その Todo を一覧から取り除かなければならない（MUST）。

#### Scenario: Todo を削除する
- **WHEN** 利用者が一覧内の Todo を削除する
- **THEN** その Todo は一覧に表示されない

### Requirement: Todo 一覧のローカル永続化
システムは、Todo の一覧および各 Todo の完了状態をブラウザのローカルストレージに保存しなければならない（MUST）。システムは、同じブラウザで再度読み込まれたとき、保存済みの一覧を復元しなければならない（MUST）。

#### Scenario: 変更後に再読み込みする
- **WHEN** 利用者が Todo を追加または完了状態を変更した後にアプリを再読み込みする
- **THEN** 変更後の Todo 一覧と各 Todo の完了状態が表示される

#### Scenario: Todo を削除して再読み込みする
- **WHEN** 利用者が Todo を削除した後にアプリを再読み込みする
- **THEN** 削除した Todo は一覧に表示されない
