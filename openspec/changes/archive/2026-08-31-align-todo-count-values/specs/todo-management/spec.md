## ADDED Requirements

### Requirement: Todo 件数のラベルと数値の配置
システムは、「すべて」「完了済み」「未完了」の各件数表示において、ラベルと右側の数値を同じ縦位置にそろえて表示しなければならない（MUST）。システムは、既存のフォント指定および各件数の色を維持しなければならない（MUST）。

#### Scenario: 件数ラベルと数値を表示する
- **WHEN** システムが Todo 件数を表示する
- **THEN** 各ラベルと対応する数値は横並びで同じ縦位置に表示される

#### Scenario: 件数が変化した後も配置を維持する
- **WHEN** Todo の操作によっていずれかの件数が更新される
- **THEN** 更新後の数値も対応するラベルと同じ縦位置に表示され、フォントと色は変わらない
